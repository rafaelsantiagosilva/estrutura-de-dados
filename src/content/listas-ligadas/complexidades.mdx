## Resumo das complexidades

| Função                              | Melhor caso | Pior caso |
| ----------------------------------- | ----------- | --------- |
| `newNo`, `newLista`, `estaVazia`    | `Θ(1)`      | `Θ(1)`    |
| `size`, `printLista`                | `Θ(n)`      | `Θ(n)`    |
| `addInicio`                         | `Θ(1)`      | `Θ(1)`    |
| `addFim`                            | `Θ(n)`      | `Θ(n)`    |
| `get`, `set`                        | `Θ(1)`      | `O(n)`    |
| `add`, `remover` (idx qualquer)     | `Θ(1)`      | `O(n)`    |
| `busca` (ineficiente)               | `Θ(n)`      | `Θ(n²)`   |
| `busca` (eficiente)                 | `Θ(1)`      | `Θ(n)`    |
| `addOrdenado`                       | `Θ(1)`      | `Θ(n)`    |
| `inverter`, `removerChave`, `tipoB` | `Θ(n)`      | `Θ(n)`    |
| `ordena` (por inserção)             | `Θ(n)`      | `Θ(n²)`   |
