## O que são?

Listas Ligadas ou **Listas Encadeadas** (nome que faz muito mais sentido) são estruturas de dados em que elementos são formados por `structs` que contêm um **valor** (ou mais) e uma **referência** para outro elemento.

> Chamamos esses elementos de **nós** (ou **nodos**)

Basicamente essas listas funcionam como correntes. Cada elemento é encadeado em outro, que por sua vez é encadeado em outro... 🔗

Abaixo temos a estrutura básica de uma lista.

```c
#include<stdio.h>
#include<stdlib.h>

typedef struct No {
    int valor;
    struct No *prox;
} No;

typedef struct Lista {
    struct No *ini;
} Lista;
```

A estrutura `No` possui uma referência para uma outra estrutura `No`, através do ponteiro (ou apontador) `prox`.

> 🎮 **Como usar as simulações:** use **▶** para ver tudo sozinho, **⏭ / ⏮** para ir passo a passo, ou arraste a barra. A linha azul no código mostra o que está sendo executado.
>
> 🟢 nó novo · 🟡 nó visitado · 🔴 nó removido
